# eww·lint

**Анализатор и оптимизатор конфигов [ElKowars Wacky Widgets](https://github.com/elkowar/eww).**
Показывает построчно, что в конфиге жжёт CPU, будит shell сотнями fork'ов в минуту и тормозит композитор, — и отдаёт готовый фикс для каждой находки.

Два интерфейса, один движок (33 правила):

- **TUI** (`eww-lint.tui.mjs`) — читает `~/.config/eww` напрямую, ноль зависимостей, чистый Node ≥ 18;
- **веб-компаньон** (этот репозиторий, Vite + React) — та же проверка в браузере: импорт папки, подсветка, скачивание TUI-скрипта.

---

## Зачем

Типичный конфиг eww-бара незаметно накапливает нагрузку:

- `defpoll` с интервалом `0.2s` — **300 запусков shell в минуту** ради цифры громкости;
- `while true; do cat ...; done` в `deflisten` — busy-loop на 100% одного ядра;
- `curl` в опросе каждые 20 секунд — TLS-рукопожатия, батарея, rate-limit;
- `blur(24px)` на пол-экрана — пересчёт фильтра композитором на каждый кадр.

eww·lint находит эти паттерны, объясняет, почему они дорогие, и считает **индекс оптимизации** и **обновления переменных в минуту** — эффект от каждого фикса виден сразу.

## TUI — основной способ

Файл [`eww-lint.tui.mjs`](./eww-lint.tui.mjs) в корне репозитория — самодостаточный скрипт без зависимостей.

```bash
node eww-lint.tui.mjs                     # по умолчанию ~/.config/eww
node eww-lint.tui.mjs ~/.config/eww       # явно
node eww-lint.tui.mjs --report            # отчёт в стиле линтера (по умолчанию вне TTY)
node eww-lint.tui.mjs --json              # для CI и скриптов
node eww-lint.tui.mjs --no-color          # без цвета (уважается и NO_COLOR)
```

Что делает при запуске:

1. рекурсивно обходит папку, собирает все `.yuck` и `.scss` (скрытые каталоги и `node_modules` пропускаются);
2. определяет корневые `eww.yuck` / `eww.scss` (по имени и глубине — сработает и при запуске на `~/.config`);
3. строит include-граф и прогоняет все 33 правила;
4. в TTY открывает **полноэкранный TUI**: слева файлы со счётчиками находок, справа находки, внизу детали с фиксом.

### Клавиши

| Клавиша | Действие |
| --- | --- |
| `↑↓` / `jk` | навигация |
| `tab` / `hl` | смена панели |
| `enter` | открыть находку в `$EDITOR` сразу на проблемной строке (nvim, vim, nano, `code --goto`) |
| `f` | фильтр: все → ошибки → предупреждения → советы |
| `0` `1` `2` `3` | фильтр по серьёзности |
| `r` | пересканировать |
| `space` / `JK` | прокрутить детали/фикс |
| `q` / `esc` | выход |

### Живой цикл правок

Скрипт следит за всеми папками проекта через `fs.watch`: открыли файл по `enter`, поправили `defpoll`, сохранили — TUI **пересканировал конфиг сам** и пересчитал индекс. Рескан также доступен по `r`.

### Выходные коды (CI)

| Код | Значение |
| --- | --- |
| `0` | ошибок нет |
| `1` | найдены ошибки (`--report` / `--json`) |
| `2` | папка не найдена или в ней нет `.yuck` |

Пример строки CI: `node eww-lint.tui.mjs --report --no-color` в GitHub Actions упадёт с кодом 1 и напечатает разбор.

## Веб-компаньон

```bash
npm install
npm run dev        # http://localhost:3000 (порт закреплён strictPort)
npm run build      # прод-сборка в dist/
```

Зачем, если есть TUI:

- **кнопка «Папка»** — выбрать `~/.config/eww` в диалоге браузера: все файлы подтянутся автоматически, пути разложатся для include-графа;
- кликабельные находки с переходом к строке и подсветкой, копирование фиксов;
- **кнопка «TUI»** в шапке — скачать `eww-lint.tui.mjs` или скопировать исходник прямо из браузера;
- удобно показывать разбор кому-то без терминала.

Стек: React 18 + TypeScript, Vite 6, Tailwind CSS 4. Без бэкенда, всё считается локально.

## Правила

Всего **33 правила**: 20 в yuck, 5 в include-графе, 8 в scss.

### Yuck — производительность

| Правило | Серьёзность | Что ловит |
| --- | --- | --- |
| Интервал `defpoll` < 0.3s | ошибка | сотни fork'ов shell в минуту; оправданы только для анимаций |
| Интервал `defpoll` < 1s | предупреждение | вдвое дешевле по CPU при визуально том же результате |
| Часы (`date`) быстрее 1s | предупреждение | секунды — максимум, что видно на экране |
| Громкость поллится | предупреждение | вместо `pamixer` в цикле — `deflisten` на `pactl subscribe` |
| `playerctl metadata` поллится | предупреждение | `playerctl -a metadata -F` стримит изменения сам |
| Батарея поллится | предупреждение | `cat /sys/.../capacity` → `udevadm monitor --subsystem-match=power_supply` |
| Сеть поллится | предупреждение | `iwgetid` в цикле → udev/nmcli-события |
| `curl`/`wget` в опросе | предупреждение | TLS на каждый тик; кэш в файл или интервал в минуты |
| `convert`/`ffmpeg` в опросе < 5s | предупреждение | тяжёлая обработка чаще, чем меняется исходник |

### Yuck — синтаксис и структура

| Правило | Серьёзность | Что ловит |
| --- | --- | --- |
| Несбалансированные скобки | ошибка | eww откажется парсить файл целиком |
| `defpoll` без `:interval` | ошибка | обязательное поле — конфиг не загрузится |
| Неразборчивый интервал | ошибка | eww принимает `ms`, `s`, `m`/`min`, `h` (дроби — `0.1s`, `0.5h`) и число миллисекунд; всё остальное не загрузится |
| Busy-loop в `deflisten` | ошибка | `while true` без `sleep`/`read` — 100% ядра |
| Два `defpoll` с одной командой | предупреждение | двойной fork; одна переменная на оба виджета |
| `eww update` внутри скрипта | совет | лишний клиент и IPC-раунд — выводите в stdout |
| Инлайн-скрипт > 160 символов | совет | вынести в `~/.config/eww/scripts/*.sh` |
| Неиспользуемые `defvar`/`defwidget` | совет | мёртвый код (проверка по всем файлам проекта) |

### Yuck — разметка окон

| Правило | Серьёзность | Что ловит |
| --- | --- | --- |
| `defwindow` без `:geometry` | предупреждение | окно может растянуться на весь экран — зависит от WM |
| Бар без `:exclusive true` | совет | тайловые окна будут заезжать под бар |

### Include-граф

| Правило | Серьёзность | Что ловит |
| --- | --- | --- |
| Неразрешённый include | предупреждение | путь не найден среди файлов проекта |
| Цикл include | ошибка | файл включает себя через цепочку |
| Цепочка глубже 5 уровней | совет | уплощите структуру — 2–3 уровня достаточно |
| Файл вне include-графа | совет | есть в папке, но ни один include не ссылается |
| Дубль определения между файлами | ошибка | `defpoll`/`defwidget` с одним именем в двух файлах |

### SCSS

| Правило | Серьёзность | Что ловит |
| --- | --- | --- |
| Вложенность селекторов > 4 | совет | длинные селекторы дороже матчить при перерисовке |
| Один hex повторяется ≥ 3 раз | совет | вынести в `$переменную` — смена темы в одну строку |
| `:hover` без `transition` | совет | рывок вместо плавности; 150ms почти бесплатны |
| `box-shadow` с blur ≥ 30px | предупреждение | композитор пересчитывает тень при каждой перерисовке |
| `blur()`/`backdrop-filter` | предупреждение | размытие фона пересчитывается каждый кадр |
| Универсальный селектор `*` | совет | матчится на каждый узел при каждой перерисовке |
| `!important` ≥ 3 раз | совет | борьба со специфичностью — упростите селекторы |
| Большой файл без SCSS-переменных | совет | палитра — в переменные в начало файла |

## Индекс оптимизации

```
штраф = 10 × ошибки + 5 × предупреждения + 2 × советы
индекс = 100 − штраф        (0 находок → 100, минимум — 4)
```

| Индекс | Оценка |
| --- | --- |
| 85–100 | отлично |
| 65–84 | хорошо |
| 40–64 | средне |
| < 40 | требует работы |

**обн/мин** — сумма `60 / интервал` по всем `defpoll`: сколько раз в минуту eww перезапускает shell и перерисовывает зависимые виджеты. У «типичного» бара из примера — около 730; после перехода на событийные `deflisten` остаются единицы.

```
eww-lint.tui.mjs            # standalone-TUI: Node ≥ 18, 0 зависимостей
src/
├── App.tsx                 # каркас: вкладки, импорт папки, хоткеи, статус-бар
├── components/
│   ├── CodeEditor.tsx      # редактор с подсветкой yuck/scss и номерами строк
│   ├── Diagnostics.tsx     # панель находок: фильтры, метрики, фиксы
│   ├── ScoreDial.tsx       # анимированный индекс оптимизации
│   ├── HelpModal.tsx       # инструкция «как пользоваться»
│   └── TuiModal.tsx        # раздаёт eww-lint.tui.mjs (скачать / исходник)
```

Движок продублирован в TUI-скрипте осознанно: `eww-lint.tui.mjs` должен оставаться одним файлом без сборщиков и зависимостей, который можно просто скопировать на любую машину с Node.

## Ограничения (честно)

- **Правила — эвристики**: ловят типовые паттерны по тексту, а не измеряют реальный профиль. Экзотические busy-wait'ы могут остаться незамеченными.
- **Одна SCSS-точка входа**: `@use`/`@import` внутри scss не разворачиваются — проверяйте итоговый файл.
- Поддерживается синтаксис **eww ≥ 0.4** (s-выражения). Легаси-конфиги 0.3.x с `<box>`-разметкой не разбираются.
- **Веб-версия** не имеет доступа к диску — папку выбираете вы (кнопка «Папка»); в TUI этого ограничения нет вообще.
